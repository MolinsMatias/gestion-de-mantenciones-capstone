# Gestión de mantenciones — Capstone 2026

Cliente: Bowling Service.

## Organización del repositorio

- `apps/web/`: espacio para el código del panel administrativo web.
- `apps/mobile/`: espacio para el código de la aplicación móvil.
- `apps/supabase/`: backend de Supabase: Edge Functions, migraciones SQL y pruebas.
- `docs/duoc/`: documentos de Fase 1 y Fase 2, entregas adicionales, evidencias y mockups. La Fase 1 incluye las carpetas individuales de cada integrante.
- `docs/scrum/`: enlace al tablero de Trello y registro de capturas del avance.
