# Seguimiento Scrum — Bowling Services

El equipo gestiona las tareas del proyecto en Trello. Esta carpeta conserva capturas del tablero para mostrar el avance en cada sprint y evaluación de Capstone.

## Tablero de trabajo

[HevStack | Bowling Services - Gestión de Mantenciones](https://trello.com/b/Y8f7NwuO/hevstack-bowling-services-gesti%C3%B3n-de-mantenciones)

En el tablero se pueden consultar las descripciones de las tarjetas, responsables, listas de verificación, comentarios y documentos asociados. La profesora y la comisión deben contar con acceso al tablero para revisar ese detalle.

## Organización del tablero

| Lista                    | Propósito                                                  |
| ------------------------ | ---------------------------------------------------------- |
| Recursos y Documentación | Reunir enlaces y material de apoyo del proyecto.           |
| Product Backlog          | Mantener el trabajo pendiente del producto.                |
| Sprint Backlog           | Identificar las tareas seleccionadas para el sprint.       |
| En Progreso              | Mostrar las tareas que se están trabajando.                |
| En Revisión / QA         | Revisar y validar el trabajo antes de darlo por terminado. |
| Terminado                | Registrar las tareas completadas y revisadas.              |

## Capturas de avance

Las capturas se guardan en [`capturas/`](capturas/), al cierre de cada sprint y antes de cada evaluación. Trello muestra el estado actual; las capturas conservan el estado del tablero en la fecha registrada.

- Usar nombres con fecha: `AAAA-MM-DD-sprint-01-cierre.png`. Para una evaluación, usar `AAAA-MM-DD-evaluacion-fase-1.png`.
- Mantener legibles los nombres de las listas y las tarjetas. Si hacen falta varias imágenes, agregar los sufijos `-01`, `-02`, etc.
- Agregar cada captura al registro siguiente, indicando su fecha, sprint o evaluación y una breve descripción del avance.
- Conservar las capturas anteriores para poder comparar el progreso.
